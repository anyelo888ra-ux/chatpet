# Contributing to ChatPet

Thanks for helping build ChatPet! 🐾

## Good first contributions

- UI and accessibility improvements
- Brain adapters
- Documentation
- Tests
- Privacy controls
- Localization
- Performance fixes

## Rules

1. Never put private API keys or server credentials in frontend code.
2. Do not add telemetry without documenting it.
3. Keep dependencies justified and documented.
4. Do not describe the demo brain as a full language model.
5. Keep changes compatible with GitHub Pages when possible.
6. Keep server-side secrets on server infrastructure.

## Pull requests

Explain what changed, why it changed, how it was tested, and known limitations.
