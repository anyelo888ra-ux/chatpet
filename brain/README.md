# ChatPet Brain

## v0.4 Local Brain+

The v0.4 brain adds:
- intent detection
- token-based similarity
- recent context over multiple messages
- basic question handling
- replaceable brain API: `reply`, `detectIntent`, and `similarity`

It remains a lightweight browser engine and does not claim to be a full language model.
